# DR02 RGMT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a DR02 RGMT flat tracking task and one-environment playback task based on the Chocolate RGMT implementation.

**Architecture:** Keep task-specific motion, MDP, and model code under `dr02_training.tasks.rgmt`. Reuse the `rsl_rl` RGMT branch's reusable Transformer primitives and follow Chocolate's task-level actor/critic composition; preserve all existing tasks. Runtime RSL-RL prerequisite: `4fc611ebdd71ec6971314ed6f5c1f4b1a7319601`.

**Tech Stack:** Python 3.12, Isaac Lab 3.0 Early Access, PyTorch, Gymnasium, RSL-RL PPO.

**Spec:** `docs/superpowers/specs/2026-10-12-dr02-rgmt-design.md`

## Global Constraints

- Follow the asset skill's project tree: `assets/isaaclab/` for simulator adapters and `assets/data/dr02/description/` for robot source data, with `<robot>` resolved to `dr02`.
- Keep existing AMP, tracking, and velocity task IDs and behavior intact.
- Use DR02 `JOINT_ORDER`, `TRACKING_BODY_NAMES`, and `TRACKING_ANCHOR_BODY`; the proprioceptive and command widths are 93 and 38 for 29 joints.
- Use 10 history frames, 21 command frames, and 128 embedding dimensions.
- Clamp all command windows to the selected source clip; do not allow a window or episode to cross clip boundaries.
- Recovery defaults are 15% reset probability, up to 200 N upward assistance, 100 million environment-step annealing, and a 3 second grace period.
- Reuse RSL-RL commit `4fc611ebdd71ec6971314ed6f5c1f4b1a7319601`; do not modify the separate RSL-RL checkout.
- Do not launch training or fetch motion data as part of this implementation.
- Do not add or run tests unless the user requests testing or verification.

## Review Focus

- Motion file lists with missing or mismatched joint/body names: the motion command must fail during initialization with the offending clip identified.
- Clips shorter than 21 frames and samples at either clip endpoint: every requested command index must remain inside that clip.
- Repeated observation reads within one simulation step and partial environment resets: cached frames must not be appended twice and reset histories must repeat the new initial frame.
- Non-recovery environments and recovery environments after 3 seconds: assistance and grace handling must not leak across masks or episodes.
- PPO construction with mixed rank-2/rank-3 observations: actor and critic must use the expected observation groups and output shapes through the pinned RSL-RL API.
